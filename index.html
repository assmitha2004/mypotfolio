PayLedger — digital wallet

PayLedger

Digital wallet and payments platform

What it does

A digital wallet. You sign up, add money and send it to other people, with daily limits and a full history. Every rupee is recorded twice, once leaving and once arriving, so the books always balance, even when many payments hit the same wallet at the same moment.

  • SELECT FOR UPDATE row locks stop double-spending: 50 simultaneous ₹10 transfers from ₹100, exactly 10 accepted.
  • Wallets are locked in a fixed id order: 0 deadlocks in 100 opposing transfers, down from 50.
  • An Idempotency-Key header means a retried payment never charges twice.
  • 43 tests against real MySQL in CI; about 300 transfers a second with the ledger balanced.

    Smart Scheduling — planner

    Smart Scheduling

    Full-stack planning platform

    What it does

    A planning app for teams. You add tasks, say which ones depend on which, and arrange them on a drag-and-drop calendar or Gantt chart. It works out the earliest the project can finish, highlights the tasks that can't slip, sends reminders, and stops two people booking the same slot.

    • Scheduling engine with cycle detection, topological sort and the Critical Path Method: 1,000 dependent tasks in about 0.6 s.
    • p95 API latency under 27 ms on a versioned Express REST API with JWT and role-based access.
    • No double-booking: optimistic versioning (409 on stale writes) plus a PostgreSQL exclusion constraint.
    • Redis and BullMQ for reminders and deadline-risk checks, pushed live over Socket.IO. 135 tests in CI.

    Kural RAG — semantic search

    Kural RAG

    Multilingual semantic search web app

    What it does

    A search engine for the Thirukkural. Ask a question in English, Tamil or Thanglish, in your own words, and it finds the most relevant of the 1,330 verses and writes a short answer that cites them, so you can check every claim against the original.

    • Hybrid search: a hand-written BM25 for exact words plus embeddings for meaning, then a reranker.
    • On a 100-question test set, the right verse in the top 5 rose from 44 to 97.
    • Two services: a FastAPI service loads the models once, caches results and keeps the API key server-side.
    • Every citation in an answer is checked in code before it's shown.
