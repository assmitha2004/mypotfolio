PayLedger — digital wallet

PayLedger

A digital wallet where money can't appear from nowhere.

  • JWT auth, top-ups, peer-to-peer transfers, daily limits and paginated history, on a double-entry ledger that stores money as integer paise.
  • SELECT FOR UPDATE row locks stop double-spending. Locking wallets in a fixed id order took deadlocks from 50 to 0 in 100 opposing transfers.
  • Idempotency-Key header plus a unique index in the same transaction, so a retry never charges twice.
  • 43 tests against real MySQL in GitHub Actions. Sustains about 300 transfers a second with the ledger balanced.

Smart Scheduling — planner

Smart Scheduling

A planner that works out the critical path for you.

  • React and TypeScript app with a drag-and-drop calendar and Gantt timeline, on a versioned Express REST API with JWT auth and role-based access.
  • Scheduling engine with cycle detection, topological sort and the Critical Path Method: 1,000 dependent tasks in about 0.6 s, p95 latency under 27 ms.
  • No double-booking under concurrent edits: optimistic versioning returns 409 on stale writes, backed by a PostgreSQL exclusion constraint.
  • Redis runs BullMQ jobs (reminders, deadline-risk checks, retries with backoff) and pub/sub that pushes events live over Socket.IO. 135 tests in CI.
